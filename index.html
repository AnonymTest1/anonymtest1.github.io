History Matters: Rethinking Benchmarks and Memory Design for Vision-Language-Action Models

Anonymous Authors
Under Review
Paper Code Dataset

Abstract

Memory is essential for robotic manipulation tasks that require reasoning beyond the current observation, such as occlusion handling, repeated action counting, and referential instruction following. Recent Vision-Language-Action (VLA) models incorporate memory through external memory banks, history tokens, or language subgoals, achieving promising gains on selected long-horizon tasks. However, these methods are evaluated on limited tasks and heterogeneous settings, making it unclear which memory mechanisms truly address different forms of history-dependent reasoning. We introduce HistoryBench, a large-scale benchmark of 16 manipulation tasks that systematically evaluate four functional memory types: temporal, spatial, object, and procedural memory. To analyze memory representations, we construct a family of memory-augmented VLA variants based on $\pi_{0.5}$ that integrate symbolic, perceptual, and recurrent memory under multiple mechanisms. Experiments reveal clear task-memory correspondences and trade-offs across representations and integration strategies. Together, HistoryBench and these structured VLA variants provide a standardized foundation for studying memory-aware VLA models in long-horizon manipulation.

HistoryBench Examples

Suite 1: Counting

Task 1.1: BinFill
Instruction: Put two green cubes into the bin and press the button to stop.
Task 1.2: PickXtimes
Instruction: Pick up the blue cube and place it on the target, repeating this action three times, then press the button to stop.
Task 1.3: SwingXtimes
Instruction: Pick up the red cube, move it to the top of the right-side target, then move it to the top of the left-side target, repeating this back-and-forth motion three times, finally put down the cube and press the button to stop.
Task 1.4: StopCube
Instruction: Press the button to stop the cube just as it reaches the target for the third time.

Suite 2: Permanence

Task 2.1: VideoUnmask
Instruction: Watch the video carefully, then pick up the container hiding the green cube.

Task 2.2: ButtonUnmask
Instruction: First press the button, then pick up the container hiding the green cube, finally pick up another container hiding the red cube.
Task 2.3: VideoUnmaskSwap
Instruction: Watch the video carefully, then pick up the container hiding the blue cube, finally pick up another container hiding the red cube.
Red-bordered frames denote the video history before execution
Task 2.4: ButtonUnmaskSwap
Instruction: First press both buttons on the table, then pick up the container hiding the red cube.

Red-bordered frames denote the video history before execution

Red-bordered frames denote the video history before execution
Task 3.4: VideoPlaceOrder

Red-bordered frames denote the video history before execution
