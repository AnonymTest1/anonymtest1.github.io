History Matters: Rethinking Benchmarks and Memory Design for Vision-Language-Action Models

Anonymous Authors
Under Review
Paper Code Dataset

Abstract

Memory is essential for robotic manipulation tasks that require reasoning beyond the current observation, such as occlusion handling, repeated action counting, and referential instruction following. Recent Vision-Language-Action (VLA) models incorporate memory through external memory banks, history tokens, or language subgoals, achieving promising gains on selected long-horizon tasks. However, these methods are evaluated on limited tasks and heterogeneous settings, making it unclear which memory mechanisms truly address different forms of history-dependent reasoning. We introduce HistoryBench, a large-scale benchmark of 16 manipulation tasks that systematically evaluate four functional memory types: temporal, spatial, object, and procedural memory. To analyze memory representations, we construct a family of memory-augmented VLA variants based on $\pi_{0.5}$ that integrate symbolic, perceptual, and recurrent memory under multiple mechanisms. Experiments reveal clear task-memory correspondences and trade-offs across representations and integration strategies. Together, HistoryBench and these structured VLA variants provide a standardized foundation for studying memory-aware VLA models in long-horizon manipulation.

HistoryBench Task Examples

Suite 1: Counting

Task 1.1: BinFill
Instruction: Put two red cubes into the bin and press the button to stop.
Challenge: streaming cubes
Task 1.2: PickXtimes
Instruction: Pick up the green cube and place it on the target, repeating this action two times, then press the button to stop.
Task 1.3: SwingXtimes
Instruction: Pick up the red cube, move it to the top of the right-side target, then move it to the top of the left-side target, repeating this back-and-forth motion two times, finally press the button to stop.
Task 1.4: StopCube
Instruction: Press the button to stop the cube just as it reaches the target for the third time.

Suite 2: Permenance

Task 2.1: VideoUnmask
Instruction: Watch the video carefully, then pick up the container hiding the green cube.
Task 2.2: ButtonUnmask
Instruction: First press the button, then pick up the container hiding the green cube, finally pick up another container hiding the red cube.
Task 2.3: VideoUnmaskSwap
Instruction: Watch the video carefully, then pick up the container hiding the green cube, finally pick up another container hiding the red cube.
Task 2.4: ButtonUnmaskSwap
Instruction: First press both buttons on the table, then pick up the container hiding the red cube.

Suite 3: Reference

Task 3.1: PickHighlight
Instruction: First press the button, then pick up all highlighted cubes, finally press the button again to stop.
Task 3.2: VideoRepick
Instruction: Watch the video carefully, then pick up the same block that was previously picked up for three times, finally press the button to stop.
Task 3.3: VideoPlaceButton
Instruction: Watch the video carefully and place the blue block on the target it was previously placed on right before the button was pressed.
Task 3.4: VideoPlaceOrder
Instruction: Watch the video carefully and place the green block on first target it was previously placed on.

Suite 4: Imitation

Task 4.1: MoveCube
Instruction: Watch the video carefully, then move the cube to the target in the same manner as before
Task 4.2: InsertPeg
Instruction: Watch the video carefully, then grasp the same end of the same peg you've picked and insert it into the same side of the box
Task 4.3: PatternTrace
Instruction: Watch the video carefully, then use the stick attached to the robot to retrace the same pattern.
Task 4.4: RouteStick
Instruction: Watch the video carefully, then use the stick attached to the robot to navigate around the sticks on the table, following the same path.
